# ✅ Week 1 Skills Checklist

Self-assessment tool to verify you've mastered Week 1: Foundations of Git.

## How to Use This Checklist

1. **Be honest** - Check only what you can do confidently without help
2. **Test yourself** - Try each skill before checking it off
3. **Review** - If you can't check something, review that day's lesson
4. **Track progress** - Come back after practice to check more items

**Goal:** Check off ALL items before moving to Week 2.

---

## 📦 Installation & Setup (Day 1)

### Basic Installation

* [ ] I can check if Git is installed (`git --version`)
* [ ] I successfully installed Git on my operating system
* [ ] I configured my username (`git config --global user.name`)
* [ ] I configured my email (`git config --global user.email`)
* [ ] I can view my Git configuration (`git config --list`)

### GitHub Account

* [ ] I created a GitHub account
* [ ] I can log in to GitHub successfully
* [ ] I understand the difference between Git and GitHub

### Understanding

* [ ] I can explain what version control is
* [ ] I can explain why developers use Git
* [ ] I understand what the `.git` folder contains
* [ ] I know what a commit is
* [ ] I know what a repository is

---

## 📁 Repositories (Day 2)

### Creating Repositories

* [ ] I can initialize a new repository (`git init`)
* [ ] I can create a new repository on GitHub
* [ ] I understand what "initializing" means

### The Three Areas

* [ ] I can explain the Working Directory
* [ ] I can explain the Staging Area
* [ ] I can explain the Repository (.git)
* [ ] I understand the workflow: Working → Staging → Repository

### Basic Workflow

* [ ] I can check repository status (`git status`)
* [ ] I can stage files (`git add`)
* [ ] I can commit changes (`git commit -m`)
* [ ] I can view commit history (`git log`)
* [ ] I can stage all changes (`git add .`)

### Remote Connection

* [ ] I can add a remote repository (`git remote add origin`)
* [ ] I can push commits to GitHub (`git push`)
* [ ] I can view remote repositories (`git remote -v`)
* [ ] I understand what "origin" means

---

## 🔧 Basic Commands (Day 3)

### Status & History

* [ ] I use `git status` regularly to check my repo
* [ ] I can view compact commit history (`git log --oneline`)
* [ ] I can view detailed commit history (`git log`)
* [ ] I understand what each part of a commit shows

### Viewing Changes

* [ ] I can see unstaged changes (`git diff`)
* [ ] I can see staged changes (`git diff --staged`)
* [ ] I understand the diff output format

### Commit Messages

* [ ] I write clear, descriptive commit messages
* [ ] I use present tense in commit messages
* [ ] I keep commit messages under 50 characters
* [ ] I understand why good commit messages matter

### File Operations

* [ ] I can stage specific files
* [ ] I can stage multiple files at once
* [ ] I can commit changes
* [ ] I can view which files Git is tracking

---

## 🌐 Working with Remotes (Day 4)

### Understanding Remotes

* [ ] I understand what a remote repository is
* [ ] I know the difference between local and remote
* [ ] I understand what pushing means
* [ ] I understand what pulling means

### Cloning

* [ ] I can clone a repository from GitHub
* [ ] I understand what cloning creates
* [ ] I know when to use clone vs creating new repo

### Pushing & Pulling

* [ ] I can push commits to GitHub (`git push`)
* [ ] I can pull changes from GitHub (`git pull`)
* [ ] I understand `-u` flag in `git push -u origin main`
* [ ] I set up tracking for my branches

### Remote Management

* [ ] I can add a remote repository
* [ ] I can remove a remote repository
* [ ] I can rename a remote
* [ ] I can view all remotes and their URLs

---

## 🌿 Branching (Day 5)

### Understanding Branches

* [ ] I understand what a branch is
* [ ] I can explain why branches are useful
* [ ] I know the difference between `main` and `master`
* [ ] I understand what a "branch pointer" is

### Creating & Switching

* [ ] I can create a new branch (`git branch`)
* [ ] I can switch branches (`git checkout` or `git switch`)
* [ ] I can create and switch in one command (`git checkout -b`)
* [ ] I can list all branches (`git branch`)

### Working with Branches

* [ ] I can make commits on a branch
* [ ] I understand that changes on a branch don't affect main
* [ ] I can push a branch to GitHub
* [ ] I can delete a branch locally (`git branch -d`)

### Branch Management

* [ ] I use descriptive branch names
* [ ] I understand when to create a branch
* [ ] I can see which branch I'm currently on
* [ ] I know when to delete old branches

### Navigation

* [ ] I can open terminal/command prompt
* [ ] I can navigate directories (`cd`)
* [ ] I can list files (`ls` on Mac/Linux or `dir` on Windows)
* [ ] I can create directories (`mkdir`)
* [ ] I can check current directory (`pwd` or `cd`)

### File Operations

* [ ] I can create files from command line
* [ ] I can edit files with a text editor
* [ ] I can view file contents (`cat` or `type`)
* [ ] I'm comfortable using the terminal

## 🎯 Project Skills

### Week 1 Project

* [ ] I completed the Week 1 project
* [ ] My project is on GitHub
* [ ] My project has multiple commits
* [ ] My project has a meaningful README
* [ ] I used branches in my project

### Best Practices

## 🧪 Practical Skills

### Problem Solving

* [ ] I can find and fix "not a git repository" error
* [ ] I can unstage files I accidentally staged
* [ ] I can fix a typo in my last commit message (if not pushed)
* [ ] I know how to discard changes to a file
* [ ] I can check if I'm in the right directory

### Understanding

* [ ] I can explain Git workflow to someone else
* [ ] I understand the difference between staged and unstaged
* [ ] I know when to use `git add` vs `git commit`
* [ ] I understand what happens when I push
* [ ] I know what a commit hash is

---

## 📚 Conceptual Understanding

### Core Concepts

* [ ] I understand why version control exists
* [ ] I can explain the three Git areas
* [ ] I know what makes a good commit
* [ ] I understand the purpose of branching
* [ ] I can explain remote vs local repositories

### Git Internals

* [ ] I understand that commits are snapshots
* [ ] I know that branches are just pointers
* [ ] I understand that HEAD points to current location
* [ ] I know what the `.git` folder contains
* [ ] I understand that Git stores content, not diffs

## 🌟 Advanced Understanding (Optional for Week 1)

### Beyond Basics

* [ ] I understand the difference between `git add .` and `git add -A`
* [ ] I know what `--force` does in git push (and why it's dangerous)
* [ ] I understand fast-forward merges
* [ ] I can explain what "detached HEAD" means
* [ ] I know the difference between `git reset` and `git revert`
