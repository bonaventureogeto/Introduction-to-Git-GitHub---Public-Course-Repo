A comprehensive, beginner-friendly course that takes you from zero to proficient in Git and GitHub in 2 weeks. This repository contains everything you need: daily lessons, hands-on exercises, assessments, cheat sheets, and real-world projects.

## 🎯 What You'll Learn

### Week 1: Foundations of Git

* Version control fundamentals
* Installing and configuring Git
* Creating and managing repositories
* Staging, committing, and tracking changes
* Working with remote repositories
* Branching basics

### Week 2: Collaboration & Professional Workflows

* Merging branches and resolving conflicts
* Pull requests and code review
* Forking and contributing to open source
* Undoing mistakes safely
* GitHub Issues and project management
* Team collaboration workflows

## 🏗️ What You'll Build

* **Week 1 Project:** Personal profile repository with proper Git workflow

* **Capstone:** Comprehensive project combining all skills

## 🚦 Quick Start

### Prerequisites

* A computer (Windows, macOS, or Linux)
* Internet connection
* No prior Git or programming experience needed!

### Setup (10 minutes)

1. **Install Git** - Follow our detailed [Setup Guide](SETUP.md)
2. **Create GitHub Account** - Free at [github.com](https://github.com)
3. **Configure Git:**

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "your@email.com"
   ```

4. **Start Learning** - Begin with [Week 1, Day 1](course/week1/day1.md)
